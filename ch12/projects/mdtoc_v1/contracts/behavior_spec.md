# mdtoc 동작 계약 (behavior spec)

기준 구현: `python_src/mdtoc.py` (1판, 승인일 2026-10-30, Python 3.12)
다른 언어로 재구현할 때 아래 항목이 같아야 한다. "비교 안 함"으로 적힌 항목만 예외다.

## 1. 실행

```
mdtoc [FILE] [--min-level N] [--max-level N] [--json]
```

- FILE을 생략하거나 `-`이면 표준 입력을 읽는다
- `--min-level`, `--max-level`: 1~6의 정수, 기본 1과 6. min이 max보다 크면 사용법 오류
- 옵션 약어는 받지 않는다(`--json`을 `--js`로 쓰면 사용법 오류). 같은 옵션이 여러 번 오면 마지막 값
- `-h`, `--help`: 도움말과 종료 코드 0. 도움말 내용은 비교 안 함

## 2. 입력 해석

입력 전체를 UTF-8로 해석한다(BOM을 따로 처리하지 않는다. 첫 줄이 BOM으로 시작하면 그 줄은 제목이 아니다). 그다음 Python `str.splitlines()`로 줄을 나눈다. 즉 `\n`, `\r\n`, `\r`뿐 아니라 `\v`, `\f`, `\x1c`, `\x1d`, `\x1e`, `\x85`, ` `, ` `도 줄 경계다.

각 줄을 위에서부터 본다.

1. **코드 블록 시작**: 앞 공백 0~3칸 뒤에 같은 글자 3개 이상(`` ` `` 또는 `~`)으로 시작하는 줄. 백틱 블록은 나머지 부분(정보 문자열)에 백틱이 있으면 시작이 아니다
2. **코드 블록 끝**: 블록 안에서, 앞 공백 0~3칸 뒤에 시작과 같은 글자가 시작한 개수 이상 오고, 그 뒤가 공백·탭뿐인 줄. 문서가 끝날 때까지 닫히지 않으면 끝까지 블록이다
3. 코드 블록 안의 줄은 제목이 아니다
4. **제목**: 앞 공백 0~3칸 뒤에 `#` 1~6개, 그 뒤에 공백·탭이 하나 이상 오거나 줄이 끝나는 줄. 수준은 `#`의 개수
5. 제목 문자열: `#` 뒤의 공백·탭 다음부터 줄 끝까지에서, 끝의 닫는 `#` 묶음(앞에 공백·탭이 있거나 문자열 전체가 `#`인 경우, 뒤의 공백·탭 포함)을 지우고 Python `str.strip()`으로 앞뒤 공백(Unicode 공백 전체)을 지운다. 결과가 비면 제목으로 치지 않는다

Setext 제목(밑줄 `===`, `---`)과 들여쓴 코드 블록, 인라인 표시(`*`, `` ` `` 등)는 따로 처리하지 않는다. 제목 문자열은 그대로 쓴다.

## 3. 앵커(slug)

제목마다 문서 순서대로 앵커를 만든다.

1. Python `str.lower()`로 소문자로 바꾼다(Unicode 전체 규칙. 예: `İ`는 두 글자 `i̇`가 된다)
2. Python 정규식 `[^\w\- ]`에 맞는 글자를 지운다. `\w`는 Python `re`의 Unicode 단어 글자(글자·숫자·밑줄). 결합 문자(예: 1번에서 생긴 U+0307)는 단어 글자가 아니므로 지워진다(`İstanbul`의 앵커는 `istanbul`)
3. 공백(U+0020)을 `-`로 바꾼다
4. 같은 앵커가 앞에 있었으면 `-1`, `-2`, …를 붙인다(같은 기본 앵커가 나온 횟수로 센다)

`--min-level`, `--max-level`로 걸러 내는 제목도 4번의 횟수에는 들어간다(문서 안의 실제 앵커 번호와 같게 하려는 것).

4번은 기본 앵커별 횟수만 세므로, 서로 다른 제목이 같은 앵커를 가질 수 있다(예: `# A`, `## a`, `# a-1` 순서면 둘째와 셋째가 모두 `a-1`). 기준 구현의 동작 그대로다.

## 4. 출력

- 기본: 걸러 낸 제목마다 한 줄 `<들여쓰기>- [<제목>](#<앵커>)` 과 `\n`. 들여쓰기는 공백 2칸 × (수준 − `--min-level`). 제목이 없으면 아무것도 출력하지 않는다
- `--json`: `[{"level":<수준>,"text":<제목>,"slug":<앵커>}, ...]`를 Python `json.dumps(..., ensure_ascii=False)` 형식(`, `와 `: ` 구분자, ASCII가 아닌 글자는 그대로, 제어 문자는 `\u00XX`)으로 한 줄, 끝에 `\n`. 제목이 없으면 `[]`
- 출력은 UTF-8, 줄바꿈은 `\n`

## 5. 오류와 종료 코드

| 상황 | 종료 코드 | stdout | stderr |
|---|---|---|---|
| 정상 | 0 | 위 출력 | 없음 |
| 사용법 오류(알 수 없는 옵션, 범위 밖 수준, min > max 등) | 2 | 없음 | 비어 있지 않음(내용은 비교 안 함) |
| 파일을 읽지 못함(없음, 디렉터리, 권한) | 1 | 없음 | `mdtoc: error: cannot read <FILE>: ...` 한 줄(내용은 비교 안 함) |
| UTF-8이 아닌 입력 | 1 | 없음 | `mdtoc: error: <FILE>: not valid UTF-8` (표준 입력이면 `<stdin>`)과 `\n` |

## 6. 범위 밖

- 표준 입출력이 닫힌 채 실행하는 경우, 쓰기 실패
- 입력 크기 한도(메모리에 다 올릴 수 있는 크기까지만)
